# لوحة الإدارة المختصرة

المسار والمصادقة والأدوار لم تتغير. القائمة الجانبية أصبحت مجموعات قابلة للطي، مع الرئيسية مستقلة والخروج أسفلها. تفتح مجموعة الصفحة الحالية تلقائيًا ويمكن طي جميع المجموعات. الهاتف يستخدم درجًا يدعم لوحة المفاتيح وEscape وحصر التركيز.

| المجموعة | الصفحات |
| --- | --- |
| المؤسسات التعليمية | الجامعات والكليات، التخصصات الأكاديمية، شروحات المواد |
| المحتوى | الأخبار والمقالات، الفعاليات والمواعيد، البرامج التدريبية، الروابط والخدمات |
| التسويق | الإعلانات، محتوى الصفحة الرئيسية |
| التكاملات | مصادر الاستيراد، مزامنة eStudy24، سجل العمليات |
| الإدارة والإعدادات | المشرفون والصلاحيات، إعدادات المنصة، إعدادات متقدمة |

المتقدم يضم التصنيفات وسجل الإدارة ووثائق API وربط تصنيفات الشروحات. يعرض ربط التصنيفات أسماءها في اختيار جاهز بدل طلب رقمها. صفحة شروحات المواد قائمة بحث محلية للقراءة فقط؛ تحرير المصدر يبقى على eStudy24. إدارة الربط وإجراءاتها الجماعية باقية في المتقدم، والمزامنة وسجلها في قسم التكاملات. لا وظائف مكررة ولا تغيير لمنطق الاستيراد.

إعدادات المنصة تجمع دعم تيليجرام وعدّاد الزيارات. رابط إعدادات العدّاد القديم يعيد التوجيه إليها. شاشة تسوية المؤسسات القديمة أعيد توجيهها إلى إدارة المؤسسات، حيث يظهر إجراء التنظيم النهائي مرة واحدة فقط حتى نجاحه.

قوائم المحتوى تستخدم عنوانًا وعددًا مختصرًا وفلاتر وإجراء إضافة وقائمة وإشعارات. معرفات الروابط وSEO أصبحت ضمن خيارات متقدمة في النموذج، وتشخيص العمليات داخل تفاصيل قابلة للتوسيع. حُذفت مقدمات متكررة وقُللت المسافات؛ لم تُحذف معلومات ضرورية للتأكيد أو أخطاء الفحص. شريط الإجراءات الجماعية يبقى مختصرًا قبل التحديد، وتظهر الإجراءات بعده؛ النطاق والأعداد والتأكيدات باقية، وإيصال العملية متاح في التفاصيل.

Owner يحتفظ بالإدارة العالمية. Editor يحتفظ بوظائف المحتوى وقراءة المؤسسات/المصادر ووثائق التكامل حسب الصلاحيات السابقة، دون الحسابات والإعدادات العالمية والربط والمزامنة. Ambassador يرى الرئيسية والتخصصات والمحتوى المخوّل لجامعته فقط. الخلفية تعيد التحقق من الصلاحيات ونطاق الجامعة؛ القائمة ليست حماية أمنية بحد ذاتها.

الاختيار الجماعي والتأكيدات والتدقيق ورفع الملفات وروابط الجامعة العامة ونقاط n8n لم تتغير. لا حسابات طلاب ولا ميزة تسجيل عامة.
